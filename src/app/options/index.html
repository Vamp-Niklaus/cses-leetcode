📖 Custom Adapter Documentation

To connect any third-party judge or custom backend, open adapters/custom.js in this extension folder and edit the exported runCustom function.

1. Input Parameters

Param Type Description
url string The Endpoint URL entered in this Settings page
apiKey string Optional API key / token entered in this Settings page
apiHost string Optional RapidAPI host header entered in this Settings page
language string 'cpp' | 'c' | 'python' | 'java'
code string The complete source code string to compile & run
stdin string Standard input text for the test case
timeoutMs number Max execution timeout in ms (default: 10000)
signal AbortSignal Signal for network timeout abort

2. Expected Return Shapes

Scenario Return Format
Success (Pass/Fail) { kind: "ok", result: { output: string, compileError: null, runtimeError: null, timeMs: number } }
Compile Error { kind: "ok", result: { output: null, compileError: string, runtimeError: null, timeMs: null } }
Runtime Error { kind: "ok", result: { output: string, compileError: null, runtimeError: string, timeMs: number } }
Timed Out { kind: "timeout" } (triggers automatic fallback to next judge)
Rate Limited (429) { kind: "rate-limited" } (triggers automatic fallback to next judge)
Server / Network Down { kind: "infra-error" } (triggers automatic fallback to next judge)

3. Complete Code Example in adapters/custom.js

export async function runCustom({ url, apiKey, language, code, stdin, timeoutMs, signal }) { const res = await fetch(url, { method: "POST", headers: { "Content-Type": "application/json", "Authorization": apiKey ? `Bearer ${apiKey}` : undefined }, body: JSON.stringify({ language, code, stdin }), signal }); if (res.status === 429) return { kind: "rate-limited" }; if (!res.ok) return { kind: "infra-error" }; const data = await res.json(); return { kind: "ok", result: { output: data.stdout ?? data.output ?? "", compileError: data.compileError ?? null, runtimeError: data.runtimeError ?? null, timeMs: data.timeMs ?? null } }; }
